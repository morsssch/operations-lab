# Исследование операций

Настольное приложение для лабораторной по линейному программированию и транспортной задаче. Оно показывает ход решения, формулы и таблицы. Расчёты выполняются в точных дробях.

## Запуск

| Система | Готовая сборка |
| --- | --- |
| Windows 10 или 11, x64 | Запустите `OperationsLab-Windows-x64.exe`. |
| macOS 12 или новее, Apple Silicon или Intel | Распакуйте `OperationsLab-macOS.zip` и откройте `Исследование операций.app`. |

[Скачать готовые сборки](https://github.com/morsssch/operations-lab/releases/latest). Приложение открывается в отдельном окне и работает без интернета. Для готовых сборок устанавливать Python или Node.js не нужно.

## Как пользоваться

1. Откройте вкладку метода. Кнопки **1**, **2** и **3** подставляют готовые примеры.
2. Задайте размер задачи и введите коэффициенты. Поддерживаются целые числа, дроби вроде `3/4` и десятичные числа с точкой или запятой.
3. Нажмите **Решить** или **Проверить**. Режимы **Обе панели**, **Условие** и **Решение** меняют вид окна.
4. Готовый отчёт можно скопировать или сохранить в TXT.

Для задач линейного программирования исходные переменные считаются неотрицательными. В форме доступно до 30 переменных и 40 ограничений. Для транспортной задачи доступно до 30 поставщиков и 30 потребителей.

## Методы

| Вкладка | Что показывает | Файл в `ui/methods/` |
| --- | --- | --- |
| Симплекс-метод | Каноническую форму, оценки, выбор ведущего элемента, пересчёт таблиц и проверку оптимальности базиса. | `simplex.js` |
| Проверка на оптимальность | Допустимость заданного плана, двойственную задачу, условия дополняющей нежёсткости и проверку найденного двойственного вектора. | `optimality.js` |
| Искусственный базис | Вспомогательную цель, вывод искусственных переменных и оптимизацию исходной цели. | `artificial-basis.js` |
| Прямая и двойственная | Двойственную постановку и получение двойственного плана по оценкам и через обратную базисную матрицу. | `primal-dual.js` |
| Двойственный симплекс | Выбор ведущей строки и столбца по оценкам. Если можно вывести верхние границы, показывает замену переменных для старта. | `dual-simplex.js` |
| Транспортная задача | Начальный план методом северо-западного угла или минимальной стоимости, потенциалы и цикл перераспределения. | `transport.js` |
| Проверка устойчивости | Интервалы коэффициентов цели и правых частей при сохранении текущего базиса. Каждый параметр изменяется отдельно. | `stability.js` |

Во вкладке **Проверка на оптимальность** введите исходную задачу и координаты готового плана. Программа выписывает равенства для положительных компонент плана и строгих исходных ограничений, затем проверяет, можно ли подобрать допустимые двойственные переменные. Обычный симплекс начинает с допустимого начального плана. Если начальную таблицу построить не удалось или её правые части отрицательны, вкладка сообщает об этом. В конце расчёта программа проверяет правые части и оценки итоговой таблицы.

## Исходники, тесты и сборка

В каждом файле метода находится логика соответствующей вкладки. Общие вспомогательные файлы лежат в `ui/methods/shared/`. Папка `native/` содержит окно macOS, папка `windows/` — окно Electron и упаковку Windows.

Для тестов нужен Node.js. Из корня проекта выполните:

```sh
node --test tests/methods.test.cjs
```

Для сборки macOS нужны инструменты командной строки Xcode:

```sh
sh native/build.sh --universal
sh native/package.sh "Исследование операций.app"
```

Для сборки Windows с macOS или Linux нужны `unzip`, `makensis` и [архив Electron для Windows x64](https://github.com/electron/electron/releases/tag/v45.3.0):

```sh
mkdir -p dist
sh windows/build.sh electron-v45.3.0-win32-x64.zip dist/OperationsLab-Windows-x64.exe
```

Скрипт также принимает путь к компилятору через переменную `MAKENSIS`.
